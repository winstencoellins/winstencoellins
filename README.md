## This repository

Personal portfolio site — minimalist, responsive landing page built with Next.js.

### Stack

- [Next.js 16](https://nextjs.org/) (App Router)
- [React 19](https://react.dev/)
- [Tailwind CSS 4](https://tailwindcss.com/)
- [Framer Motion](https://www.framer.com/motion/)
- [Bun](https://bun.sh/) (package manager)

### Features

- Sticky navigation with smooth anchor scrolling
- Experience, freelance projects, tech stack grid, and project showcase
- Dark mode
- SEO metadata and optimized images
- Content driven from `app/lib/data.ts`

### Getting started

**Prerequisites:** [Bun](https://bun.sh/) (or Node.js 20+)

```bash
git clone https://github.com/winstencoellins/winstencoellins-profile.git
cd winstencoellins-profile
bun install
bun dev
```

Open [http://localhost:3000](http://localhost:3000).

### Scripts

| Command | Description |
| --- | --- |
| `bun dev` | Start development server |
| `bun build` | Production build |
| `bun start` | Run production server |
| `bun lint` | Run ESLint |

### Project structure

```
app/
├── components/
│   ├── layout/      # Header, Footer
│   ├── sections/    # Hero, Experience, TechStack, Projects, etc.
│   └── ui/          # Buttons, animations, theme toggle
├── lib/
│   ├── data.ts      # Site copy, projects, experience
│   └── scroll.ts    # Anchor scroll helpers
public/images/       # Project screenshots & profile photo
```

### Customize content

Edit **`app/lib/data.ts`** for your name, bio, work history, projects, tech stack, and social links. Add project images under **`public/images/`** and import them in `data.ts`.

### Deploy

Deploy on [Vercel](https://vercel.com) (recommended for Next.js):

1. Push this repo to GitHub
2. Import the project in Vercel
3. Deploy — no extra config required
